# Engineering Studio FULL v1.0.0

Офлайн PWA в визуале утверждённого концепта Engineering Studio.

## Уже работает
- Живой параметрический эскиз фланца: D1, PCD, отверстие, толщина, число и диаметр отверстий.
- 3D-псевдомодель, которая перестраивается вместе с параметрами.
- Инженерный калькулятор с точностью 0.1 / 0.01 / 0.001 / 0.0001.
- Размерные цепи.
- Допуски и посадки H7/H8/H9 + h6/g6/k6/p6.
- Материалы и автоматический расчёт объёма/массы.
- Undo/Redo параметров, сохранение проекта в localStorage.
- Светлая/тёмная тема.
- PWA manifest + Service Worker для офлайн работы.
- Адаптация под iPhone: без общего горизонтального скролла, нижний Dock внутри стабильной оболочки приложения, 2 px от низа.

## GitHub Pages
Загрузите содержимое папки в корень репозитория, включите Settings → Pages → Deploy from branch → main / root.

## Важно
Это рабочая CAD/PWA основа, а не геометрическое ядро уровня SolidWorks. Для настоящих STEP/Parasolid, сложных сборок и B-Rep потребуется отдельное CAD-ядро/WASM. Текущая сборка уже даёт интерактивный параметрический рабочий прототип для развития.
